Import data

Pull local data into your map. Run them in order — OpenStreetMap builds the base layer, then the others enrich it. All three are free and need no API keys.

OpenStreetMap
Shops, restaurants, schools, GPs, pubs, parks and more. Start here.
Food Standards Agency
Food hygiene ratings for every inspected food business. Adds missing venues and rates existing ones.
NaPTAN transport stops
Official bus stops, rail stations and tram stops from the Department for Transport.
Overture Maps open data
Open place data backed by Meta, Microsoft, Amazon and TomTom. No key needed, but the first run can take a minute.
Foursquare needs key
Rich business listings with phone numbers and websites. Add a free key below, then import.

The best source for opening hours and phone numbers. Requires a key with billing enabled; one run makes 12 API calls, well inside the free monthly allowance.
